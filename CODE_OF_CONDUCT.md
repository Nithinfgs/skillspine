# Community code of conduct

Be respectful, specific, and constructive. Welcome people with different backgrounds
and experience levels. Critique ideas and code without personal attacks.

Harassment, threats, discriminatory language, sexualized conduct, publishing private
information, and deliberately disruptive behavior are not acceptable in project
issues, pull requests, discussions, or other project spaces.

Maintainers may edit or remove violating content, restrict participation, or ban
repeat or severe offenders. Responses should be proportionate to severity and
context. Good-faith reports and disagreements must not trigger retaliation.

Report conduct problems to the repository owner through the contact options on
https://github.com/Nithinfgs. Do not post private details in public reports. Include
links and enough context for a fair review. Maintainers should preserve reporter
privacy and explain moderation decisions where appropriate.
